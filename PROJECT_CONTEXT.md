# MUNDI — Product Context

## Vision
MUNDI is an independent, global-first digital media experience for a general audience. Its goal is to make world events intelligible and engaging through a mobile-first, vertical feed inspired by short-form discovery interfaces.

**Brand promise:** « Comprendre le monde n'a jamais été aussi simple. »
**Positioning:** « MUNDI — Comprendre le monde. »

## Product principles
1. Inform: what happened, with transparent attribution.
2. Explain: why it happened, its causes and context.
3. Explore: what consequences might follow, with uncertainties clearly labeled.
4. Respect users' attention and intellectual autonomy, including diversity of viewpoints.
5. Distinguish facts, analysis, speculation and opinion. Never invent reported events or sources.

## Audience and launch
- General audience; worldwide editorial scope.
- Initial interface and editorial language: French; internationalization-ready.
- Platform: responsive web, with Netlify as the intended host.
- Formats: flash shorts (30–60s), explainers (1–3m), longer analyses (3–8m), infographics.
- Production style: voice-over, visuals, animations, captions, documentary imagery and maps.
- Content model: curated reporting + original analyses + selected expert contributions; AI-assisted with human editorial review.

## Initial editorial topics
Geopolitics, economics, finance, industry, critical materials and resources, energy, recycling, environment, technology, business, Africa, science and society.

## MVP scope
- Vertical discovery feed, functional scrolling/swiping and story cards.
- Explore by topic and search through demo content.
- Article/deep-dive page with content, source links and update dates.
- Bookmark/save interaction (local storage acceptable for first demo).
- Responsive navigation and accessible UI.
- Clear distinction between demo fixtures and real news.
- No comments, payments or automated news ingestion in first iteration.

## Design direction
Editorial, premium, accessible, calm but lively.
- Night navy: #101D30
- Blue accent: #246BCE
- Warm ivory: #F3F0E8
- Mint accent: #20B99A
- Typography: DM Sans or Inter; an editorial headline treatment is welcome.
- Strong mobile UX without neglecting desktop.

## Technology recommendation (adapt to existing code if present)
Next.js + TypeScript + Tailwind CSS; Netlify deployment. Avoid external credentials, database and media streaming until interface prototype is reviewed. Later options: Supabase, a hosted video service, analytics and an editorial CMS.

## Milestones
1. Establish shared repository guidelines and architecture.
2. Implement polished functional UI with clearly labeled demo content.
3. Validate on mobile and desktop, fix usability/accessibility issues.
4. Add editorial workflow, content sourcing and human checks.
5. Prepare preview on Netlify, then production release with founder approval.

## Founder collaboration
The founder does not write code. Explain decisions in accessible French, report what has changed, provide preview links/steps, and clearly flag decisions requiring approval.
