# MUNDI — Sauvetage ponctuel des brouillons déjà vérifiés

Le 23 novembre 2026, le run [45217101017](https://github.com/nadaudjed/mundi/actions/runs/45217101017) a traité
12 missions Anthropic (9 brouillons, 4 verdicts favorables), mais son push sur
`editorial-stock` a échoué car le collecteur RSS avait entre-temps mis à jour
la branche. La publication n'a pas été tentée.

Le workflow `recover-agents-2026-11-23.yml` télécharge **l'artefact GitHub privé d'origine**
(ce n'est pas un nouveau modèle ou un nouveau texte inventé), vérifie son identité,
sauvegarde ses dossiers dans le registre interne, puis applique les **contrôles de
publication existants** : verdict favorable, preuve des assertions, deux organismes
sources indépendants, liens réellement joignables, doublons refusés et plafond journalier.

Les sujets insuffisamment justifiés demeurent privés. Aucun accès à l'API Anthropic
n'est transmis à ce workflow, donc **aucun appel de modèle supplémentaire**.
Le workflow ne garantit pas de publication : un lien mort, une vérification
insuffisante ou le plafond du jour peuvent empêcher toute diffusion.

La PR #69 résout la cause de ce conflit pour les exécutions futures.
L'artefact d'origine a une durée de conservation de 14 jours ; le workflow
de récupération est destiné à un usage exceptionnel, pas à une rediffusion
périodique. Les rapports de décisions sont conservés 30 jours.
