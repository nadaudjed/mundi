# MUNDI — Travail en équipe IA

## Répartition
- **Fondateur** : vision, choix éditoriaux, approbation des contenus factuels et des modifications sensibles.
- **Claude Code** : développement du fil immersif, médias, expérience mobile, tests de parcours et corrections d'interface. Mission en cours : [issue #5](https://github.com/nadaudjed/mundi/issues/5).
- **ChatGPT** : architecture, production éditoriale, intégration, contrôle qualité, développement complémentaire et suivi GitHub.

## Mode de coordination
1. Consulter les issues et PR ouvertes avant toute intervention.
2. Partir de main à jour sur une branche de travail distincte.
3. Résumer les changements, tests et limites dans la PR.
4. Les PR techniques standard sont candidates à une fusion automatique si la qualité GitHub réussit.
5. Les changements de publication éditoriale, de workflow et d'infrastructure restent soumis à une validation explicite.
6. Netlify suit main pour la production ; surveiller ses résultats de déploiement.

## Limites de communication
ChatGPT et Claude Code n'échangent pas directement des messages en temps réel. GitHub (issues, branches et PR) est le canal partagé ; le fondateur ouvre la mission Claude Code dans son application.
